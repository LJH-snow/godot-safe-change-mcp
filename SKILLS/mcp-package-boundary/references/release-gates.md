# MCP Package Release Gates

## Runtime allowlist

The current package.json files list is the source of truth. The checked
runtime boundary includes:

- bin/mcp-server.mjs
- .mcp-use/build
- godot-plugin
- README.md and README.en.md
- LICENSE
- .env.example
- package metadata generated by npm

Development sources, tests, docs, CI files, build scripts, agent/skill
directories, planning/progress files, and package-lock.json must stay out of
the tarball unless the allowlist is intentionally changed with matching smoke
coverage.

## Required checks

The human release checklist in docs/RELEASE.md requires npm ci, npm test,
typecheck, build, package:check, a Godot runtime smoke, and git diff --check.
The CI release gate is the check job, npm package boundary job, and the two
Godot runtime jobs for versions 4.5.1 and 4.7.2. Keep the exact commit SHA and
run URL with the handoff.

Do not run npm publish as part of a package-boundary check. Publishing is a
separate authorized action after the worktree and exact revision are verified.
