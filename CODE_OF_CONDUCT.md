# Contributor Covenant Code of Conduct

## Our pledge

We are committed to making participation in this project a respectful, constructive, and safe experience for everyone.

## Expected behavior

- Be respectful of different technical backgrounds and opinions.
- Focus feedback on reproducible behavior, constraints, evidence, and user impact.
- Assume good intent while remaining precise about safety and security concerns.
- Accept correction and keep discussions focused on improving the project.

## Unacceptable behavior

- Harassment, discrimination, threats, doxxing, or personal attacks.
- Publishing private information, credentials, or project files without permission.
- Deliberately bypassing or weakening the project's safety boundaries.

## Enforcement

Report a problem privately through the repository owner's GitHub profile or the repository's available private security/reporting channel. Public issues are for reproducible technical problems, not personal disputes.

Project maintainers may remove comments, close discussions, or restrict participation when necessary to protect the community.
